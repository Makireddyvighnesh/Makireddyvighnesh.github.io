Three things I've learned

Read the errors before you touch the architecture.

Our Malayalam speech model kept slipping into other languages mid-sentence. The fix wasn't a bigger model. Error analysis showed the confusion, and masking the language token at decode time cut Malayalam errors by about 40%.

Reward the thing you actually want.

For text-to-SQL I fine-tuned Qwen3-4B, then trained it with GRPO using one reward: does the query run and return the right rows. That beat the supervised checkpoint by 10% pass@1 and reached 86.7% pass@4 on Spider and 70.7% on BIRD. I've kept building RL environments since.

A model isn't done until someone can talk to it.

A voice agent that keeps talking while you interrupt it feels broken, whatever its accuracy. So I built barge-in: when the user speaks, generation and playback stop. Latency, cancellation and serving are part of the model, which is why I'm now writing an inference engine.
