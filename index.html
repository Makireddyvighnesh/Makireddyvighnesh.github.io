RL post-training · research project

Teaching a 4B model to write SQL with GRPO

A small model, trained with a reward that only cares whether the query actually returns the right answer.

+10%pass@1 over the SFT checkpoint
86.7%pass@4, Spider dev
70.7%pass@4, BIRD dev
9,000+validated chain-of-thought SQL examples

The problem

Supervised fine-tuning teaches a model to imitate SQL that looks right. Text-to-SQL is judged on whether the query runs and returns the right rows, which imitation doesn't optimize for.

What I built

  • Generated reasoning traces with DeepSeek and kept only the 9,000+ that executed correctly on Spider and BIRD
  • SFT of Qwen3-4B-Instruct with 4-bit QLoRA
  • GRPO on top, with an execution-based reward that runs each candidate query against the database

Stack

Qwen3-4B · DeepSeek · QLoRA · GRPO · Tinker API

ASR · Aiverbalyze · in production

One speech model for 12 Indian languages

Fine-tuned a FastConformer RNN-T model (Nemotron ASR 3.5) to transcribe 12 Indic languages, then chased down where it went wrong.

12languages, one model
19.2%average OIWER
~40%Malayalam improvement

The problem

Multilingual models confuse closely related languages. Malayalam transcripts kept drifting into other scripts mid-sentence, and there wasn't enough real domain data to train it out.

What I built

  • Synthetic, domain-specific multilingual datasets for fine-tuning
  • WER and error analysis that traced the failure to cross-language confusion
  • Masked language-token conditioning, which forced the decoder to stay in the target language

Stack

NeMo · FastConformer · RNN-T · PyTorch

Agents · Aiverbalyze · real-time

A voice agent you can interrupt

Speech in, LLM, speech out, built to cope with real phone audio and people who talk over it.

The problem

Voice agents that keep talking when you cut in feel broken. An offline ASR model also falls apart on noisy, unsegmented live audio.

What I built

  • Barge-in: when the user speaks, active LLM generation and TTS playback are cancelled
  • Streaming preprocessing with DeepFilterNet denoising and Silero VAD v6
  • Utterance segmentation so an offline ASR model works in real time

Stack

STT → LLM → TTS · DeepFilterNet · Silero VAD
