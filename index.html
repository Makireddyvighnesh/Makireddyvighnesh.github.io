Teaching a 4B model to write SQL with GRPO RL +10% pass@1 over SFT. 86.7% pass@4 on Spider, 70.7% on BIRD.

Problem. Fine-tuning on examples teaches a model to write SQL that looks right. But a query is only right if it runs and returns the right rows.

Approach. I generated reasoning traces with DeepSeek and kept the 9,000+ that checked out on Spider and BIRD. I fine-tuned Qwen3-4B on them with 4-bit QLoRA, then switched to GRPO with a reward that executes every candidate query against the database.

Result. RL on top of SFT improved pass@1 by 10%. The 4B model reaches 86.7% pass@4 on Spider dev and 70.7% on BIRD dev.
